# ⚽ Khela Hobe - Sports Ground Booking System

A complete, dynamic PHP/MySQL web application that lets users discover, book, and pay for football, cricket, and basketball turfs.

## ✨ Features

- **User Roles**: Dedicated dashboards for Users, Ground Owners, and Admins.
- **Booking System**: Check availability, book slots, and cancel bookings.
- **Payments**: Integrated bKash manual payment flow with payment confirmations.
- **Authentication**: Google Login, manual registration, and secure session handling.
- **Reporting**: Admin audit logs, booking statistics, and financial reports.
- **Receipts**: Generate PDF invoices using Dompdf.
- **Notifications**: Email alerts via PHPMailer.

## 🛠️ Tech Stack

- **Backend**: PHP (Procedural)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: MySQL
- **Libraries**: PHPMailer, Dompdf, Font Awesome
